---
description: Record an inspector's visit in one go: the inspection, the readings, the valve tests, the anomalies and the new certificate
---

Take the inspector's report from the operator (pasted, or a file). Read back what you will record, then run `inspect`, `reading` for each point, `test-valve` for each valve, `anomaly` for each finding and `certify` if a certificate was issued. Then run `equipment <tag>` and say what changed: new rate, remaining life, next due dates, findings cleared or raised.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
